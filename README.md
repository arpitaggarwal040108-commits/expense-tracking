# Personal Expense Tracker
## Overview
Personal Expense Tracker is a simple Python-based application that helps users record and manage their daily expenses. The program allows users to add expenses, view all recorded expenses, and filter expenses by category. All expense data is stored permanently in a text file (`data.txt`) using file handling.
## Features
* Add new expenses with date, category, amount, and optional notes.
* View all recorded expenses in a formatted table.
* Filter expenses based on category.
* Calculate total expenses and category-wise totals.
* Simple menu-driven interface using Python's `match-case` statement.
* Stores data in a text file for future access.
## Categories
The application supports the following expense categories:
* Food
* Transport
* Entertainment
* Others
## Technologies Used
* Python
* File Handling
* Functions
* Loops
* Conditional Statements
* Match-Case (Switch Case)
* Exception Handling
## Data Storage
Expense records are stored in `data.txt` in the following format:
DD/MM/YY,Category,Amount,Note
Example:
08/06/26,Food,250,Lunch
08/06/26,Transport,100,Metro Ticket
## Purpose
This project demonstrates the practical use of Python programming concepts such as file handling, user-defined functions, data processing, and menu-driven applications while providing a useful tool for tracking personal expenses.
